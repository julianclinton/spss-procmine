AF PROCMINE Extension Command

Run process mining on a set of cases.

AF PROCMINE PROCESS_ID=“Case-id” ACTIVITY_NAME=“Activity” START_DATE=“Start-Date” END_DATE=“End-Date”*

/SAVE MODELFILE=“process_model.json”

* Required
** Default

AF PROCMINE /HELP prints this information and does nothing else.

AF PROCMINE PROCESS_ID="Case-id" ACTIVITY_NAME="Activity" START_DATE="Start-Date" END_DATE="End-Date" /SAVE MODELFILE=process_model.json.

MODELFILE

MODELFILE causes the process model to be written to the specified file.

The AF PROCMINE command requires the Python Integration Plug-in package.
